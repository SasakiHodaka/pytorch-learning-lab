# Lessons

このフォルダには、PyTorchを基礎から学ぶための教材コードを番号順に置きます。

## 学び方

1. コードを上から一行ずつ読む。
2. 実行前に、何が表示されるか予想する。
3. コードを実行する。
4. 予想と実際の結果を比べる。
5. 分からない行をそのままにせず、コメントや学習記録を残す。

最初からすべてを暗記する必要はありません。「この行は何をするのか」を少しずつ
説明できるようになることを目指します。
