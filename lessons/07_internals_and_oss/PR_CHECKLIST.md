# Pull Request Checklist

- [ ] The PR is connected to an actionable Issue when required.
- [ ] I can explain every changed line without relying on generated text.
- [ ] The change is minimal and contains no unrelated formatting or refactoring.
- [ ] A regression test fails before the fix and passes after it.
- [ ] Normal, boundary, and error cases were considered.
- [ ] Focused tests, relevant tests, and required linters pass.
- [ ] The description states why the change is needed and how it was tested.
- [ ] Public behavior, compatibility, documentation, and error messages were checked.
- [ ] I re-read the current Contributor Guide and `CONTRIBUTING.md`.
- [ ] I reviewed the final diff as if I were the Maintainer.
