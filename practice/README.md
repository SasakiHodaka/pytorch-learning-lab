# Practice

`exercises.py`の`TODO`を、完成コードを先に見ずに実装します。コードを書く前に、
仕様を「入力」「出力」「制約・例外」に分け、処理手順を日本語または疑似コードで
書き出してください。20〜30分試しても進めない場合だけ、対応するヒントや関数を
一つずつ確認します。

## Workflow

1. 問題文から入力、出力、制約、edge caseを抽出する。
2. 具体例を最低2つ作り、期待結果を決める。
3. 処理を小さな手順に分けてから、対象関数を実装する。
4. 対象テストだけを実行する。
5. failureを「期待」「実際」「原因仮説」に分けて読む。
6. 仮説を一つだけ検証する修正を行い、再度テストする。
7. 成功後、変数名、重複、edge caseを見直す。
8. 最後に`practice/solutions.py`と比較し、判断の違いを説明する。

## Skills to train

- **Decomposition**: 大きな要求を実装可能な小さな処理へ分ける。
- **Precision**: 曖昧な言葉を入力、出力、型、例外として定義する。
- **Hypothesis testing**: 勘で直さず、失敗原因の仮説を立てて確かめる。
- **Trade-offs**: 動くだけでなく、読みやすさや拡張性も比較する。
- **Communication**: 実装理由と検証結果を他者が再現できるように伝える。
